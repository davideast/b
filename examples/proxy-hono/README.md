# Hono Proxy Example

This example demonstrates how to create a simple proxy server using Hono.

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

## Running the server

1. **Start the server:**
   ```bash
   npm start
   ```

The server will start on port 3000. You can access it at [http://localhost:3000](http://localhost:3000).
