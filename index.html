The top 5 recurring themes extracted from approximately 50 feedback emails.

1. SDK Functionality & Improvements

High demand for session management controls (cancel), webhook support, and helper methods for data handling.

2. Code Generation & Refactoring

Users are leveraging the tool for diverse tasks: React components, SQL queries, Dockerfiles, i18n, and optimization.

3. Integrations & Workflows

Strong interest in connecting with Google Workspace (Docs, Sheets), Slack, GitHub Actions, and databases.

4. Prompt Engineering

Users seek best practices, "dry run" capabilities, and ways to handle large context prompts.

5. Documentation & Learning

Requests for video tutorials, changelogs, integration patterns, and more concrete examples.

SDK Feature Requested by Marcus B.

Session Cancellation

JulesApp.cancelSession(id)

Add a method to programmatically terminate a session. Users need a way to stop runaway or incorrect sessions without using the UI.

Architecture Requested by Ian K.

Webhook Support

onComplete: 'https://...'

Native webhook support for session completion. Allows users to avoid polling with `waitFor` and handles long-running tasks more reliably.

DX / Tooling Requested by Evan F.

Artifact Retrieval Helper

session.getArtifacts()

A helper method to easily retrieve generated files (HTML, JSON, etc.) from a completed session, abstracting away the need to parse the activity log.
